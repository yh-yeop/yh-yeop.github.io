# yh-yeop.github.io

공개 저장소들을 소개하고 바로 열어 볼 수 있게 모아 둔 페이지.

👉 https://yh-yeop.github.io/

- 빌드 없음. `index.html` 한 파일.
- 소개 글은 `index.html` 안의 `PROJECTS`(카드) · `PRACTICE`(접힌 수업·연습 목록)에서 고친다.
- 업데이트 날짜 · 별 · 라이선스 · 최신 버전과 설치 파일 링크는 GitHub API에서 그때그때 불러온다(10분 세션 캐시). 불러오지 못하면 릴리스 페이지 링크로 대신한다.
- `PROJECTS`·`PRACTICE`에 없는 새 공개 저장소는 '기타' 분류 카드로 자동 추가된다.
- `#maple` `#web` `#app` `#game` 처럼 주소 끝에 분류를 붙이면 그 분류만 걸러서 열린다.
