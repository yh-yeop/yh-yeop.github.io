메이플스토리 메소 장부 · 보스 수익 · 목표 도달일 계산기

메소를 어디서 벌고 어디에 썼는지 적고, 캐릭터마다 도는 보스로 한 주에 얼마가 들어오는지 계산해서, 목표 메소에 언제 닿는지 알려 줍니다. 가입 없이 브라우저에서 바로 쓰고, 기록은 내 기기에 저장됩니다.

하는 일

  • 메소 장부

    사냥 · 보스 · 거래 수입과 강화 · 큐브 같은 지출을 적고, 달마다 통계와 예산을 봅니다. 잔고를 확인하면 적지 않은 차이도 드러납니다.

  • 캐릭터별 보스 수익

    캐릭터마다 도는 보스 · 난이도 · 파티 인원을 고르면 주간 · 월간 결정석 수익이 나옵니다. 파티는 인원수로 나누고 버림(게임 규칙).

  • 추천 구성 · 판매 제한 경고

    마지막으로 잡는 보스만 고르면 주간 루틴을 비싼 순으로 12개까지 채웁니다. 메이플ID당 주 90개 판매 제한을 넘으면 알려 줍니다.

  • 이번 주 보스 체크

    홈에서 잡은 보스만 체크하면 그만큼 장부에 수입으로 들어갑니다. 목요일에 새 주, 월간 보스는 매달 1일에 리셋.

  • 목표 도달일

    평균으로 나누지 않고 하루씩 달력을 돌려 계산합니다. 목요일 보스 · 월초 월간 보스 · 매일 사냥을 따로 셈하고, 보스를 건너뛸 주도 고릅니다.

  • 넥슨 Open API

    API 키를 넣으면 계정 캐릭터(월드 · 직업 · 레벨)를 불러오고, 잠재능력 · 에디셔널 재설정 지출을 장부에 자동으로 적습니다(추정 금액).

  • 기기 저장 · 동기화는 선택

    기본은 이 기기에만 저장합니다. 원하면 Google 로그인으로 다른 기기와 맞추고, 백업 · 복원 · CSV 내보내기도 됩니다.

  • 계산 기준 공개

    결정석 가격 기준일과 출처, 분배 · 한도 · 리셋 규칙을 화면 맨 아래에 적어 둡니다. 패치가 나오면 설정에서 가격을 바로 고칠 수 있습니다.

바로 열기 · 설치판

웹에서 바로 쓰는 게 기본입니다. 바탕화면이나 휴대폰에 앱처럼 두고 싶으면 브라우저의 '앱으로 설치'를 쓰거나 설치판을 받으세요.

  • 웹 휴대폰 · PC 브라우저에서 yh-yeop.github.io/meso_calcul. 홈 화면에 추가하면 오프라인에서도 열립니다.
  • Windows 설치 파일은 2MB가 안 됩니다. 새 버전이 나오면 열 때 한 번 묻고 스스로 업데이트합니다. Google 로그인 · 동기화도 웹과 같습니다.
  • Android APK를 받아 설치합니다(1.1.0부터). Google 로그인은 막혀 있어서, 기기를 옮길 때는 백업 · 불러오기를 씁니다.
