MP3 Checker 음악 폴더 점검

MP3의 가사 · 커버 · 태그 상태를 한눈에 보고 고치는 도구

음악 폴더를 열면 곡마다 싱크 가사(.lrc)가 있는지, 커버가 들어 있는지, 태그가 다 채워졌는지를 표로 보여 줍니다. 빠진 것만 골라 커버를 넣고, 가사를 찾고, 태그를 고치는 일을 한 화면에서 합니다. Android 판으로는 휴대폰의 음악 폴더를 그 자리에서 고칩니다.

Windows .exe Android .apk

무료 · 광고 없음 · Windows 10 · 11 · Android · 자동 업데이트 · 곡 받기는 YTDL

하는 일

  • 상태 한눈에

    곡마다 가사 · 커버 · 태그 · 스타일 상태를 표로 보고, '가사없음' · '커버없음' · '링크없음' 같은 칩 하나로 빠진 곡만 거릅니다. 검색 · 정렬 · 분류도.

  • 앨범 정리

    아티스트 → 앨범으로 묶어 보고 앨범째 고릅니다. 곡마다 원본 링크가 있으면 [순서 정렬]로 업로드 날짜순 트랙 번호를 매깁니다.

  • 태그 편집

    상세 칸에서 제목 · 아티스트 · 앨범 · 연도 · 트랙을 고치고, 이전 · 다음 곡으로 넘기며 저장합니다(Ctrl+Enter).

  • 커버 바꾸기

    스타일 이미지 · 영상 썸네일(정사각 포함) · 유튜브에서 찾기 · 이미지 링크 · 붙여넣기 · 끌어다 놓기 · 파일. 여러 곡에 한꺼번에 넣을 수 있습니다.

  • 싱크 가사 찾기

    곡 태그로 벅스에서 싱크 가사를 찾아 .lrc로 채웁니다. 제목 · 아티스트가 확실히 맞는 곡만 자동 저장하고, 애매하면 후보에서 고릅니다. 직접 검색 · 벅스 링크 · .lrc 파일도.

  • 원본 링크 찾기

    링크가 없는 곡의 원본 유튜브 영상을 찾아 태그에 적습니다. 확신이 없으면 저장하지 않고 후보를 보여 줍니다.

  • YTDL 스타일로 정리

    YTDL이 깔려 있으면 그 정리 스타일 기준으로 제목에 남은 군더더기 · 앨범 규칙을 검사하고, 제안을 한 곡씩 또는 한꺼번에 적용합니다.

  • 중복 곡 찾기

    같은 영상이거나 제목 · 아티스트가 같은 곡을 묶어 크기 · 음질 · 길이를 나란히 봅니다. 파일은 지우지 않습니다.

  • 바꾸기 전에 확인

    일괄 작업은 몇 곡의 무엇이 바뀌는지와 예시 세 곡을 먼저 보여 주고, 진행 중에는 [중지]할 수 있습니다.

쓰는 법

  1. 폴더 열기 — [폴더 선택]으로 음악 폴더를 고릅니다. YTDL을 쓰면 [YTDL 폴더 스캔] 한 번. ☆을 눌러 시작 폴더로 두면 다음부터 열 때 바로 스캔합니다.
  2. 상태 보기 — 위쪽 칩(가사없음 · 커버없음 · 링크없음 · 태그불완전 · 스타일위반)으로 손볼 곡만 남깁니다. 곡을 누르면 상세가 열립니다.
  3. 고치기 — 한 곡은 상세 칸에서, 여러 곡은 체크한 뒤 위쪽 일괄 단추(링크 자동검색 · 가사 일괄 추출 · 스타일 일괄 정리 · 커버 일괄 지정)로. 바뀔 내용을 확인하고 [적용].

스캔은 파일만 읽고 인터넷에 접속하지 않습니다. 가사 · 링크 · 썸네일 조회는 그 단추를 눌렀을 때만 합니다.

받기

  • Windows 설치 파일 MP3Checker-Setup-버전.exe를 받아 실행하고 설치 마법사를 따릅니다. Windows 10 · 11.
  • Android APK MP3Checker-Android-버전.apk를 휴대폰에서 받아 엽니다. 음악 폴더를 읽고 고치려면 처음에 '모든 파일 접근' 권한을 허용합니다.
Windows .exe Android .apk
  • 코드 서명이 없는 설치 파일이라 처음 실행할 때 Windows가 'PC 보호' 창을 띄울 수 있습니다. 추가 정보 → 실행을 누르세요.
  • Android는 Play 스토어 밖에서 받은 앱이라, 처음 열 때 '알 수 없는 앱 설치'를 받은 브라우저(또는 파일 앱)에 허용해야 합니다. 설치가 끝나면 다시 꺼도 됩니다.
  • 자동 업데이트: Windows 판은 켤 때와 6시간마다 새 버전을 확인해 뒤에서 받아 두고, 준비되면 [다시 시작해 업데이트]가 뜹니다. 그냥 닫아도 다음에 켤 때 적용됩니다. Android 판은 배너에 새 버전과 용량을 띄우고, 모바일 데이터일 때는 자동으로 받지 않습니다.

알아 둘 것

내 파일, 개인 용도로
본인이 적법하게 가진 파일을 개인적으로 정리하는 도구입니다. 찾아 넣은 가사 · 커버도 개인 감상용으로만 쓰세요. 처음 실행할 때 이 내용에 동의해야 시작됩니다.
데이터는 기기 안에
음악 파일은 이 기기 안에서 읽고 고칩니다. 설정은 기기에 저장되고(Windows는 %APPDATA%\MP3Checker), 계정이나 로그인은 없습니다.
인터넷은 단추를 누를 때만
스캔 중에는 조회하지 않습니다. 가사(벅스) · 원본 링크 · 영상 썸네일은 그 단추를 누른 곡만 찾아봅니다. 벅스가 요청을 막으면 일괄 작업은 바로 멈춥니다.
익명 사용 통계
사용 중인 기기 수를 세려고 무작위 설치 ID · 버전 · OS 종류만 하루 한 번 보냅니다. 처음 화면에서 알리고, 버전 옆 '통계 보내기'로 끌 수 있습니다.
YTDL 없이도 되나요?
네. 어떤 MP3 폴더든 됩니다. YTDL이 깔려 있으면 그 저장 폴더를 바로 열고, YTDL의 정리 스타일로 검사 · 정리하는 기능이 더해집니다.
