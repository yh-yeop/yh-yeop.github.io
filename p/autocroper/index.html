AutoCroper 흰 여백 자르기

스캔한 사진의 흰 여백을 자동으로 잘라 내는 도구

흰 종이 위에 올려 스캔한 사진을 넣으면 둘레의 흰 여백을 알아서 잘라 냅니다. 비스듬히 놓인 사진은 똑바로 세우고, 스캐너에 여러 장을 한꺼번에 올려 찍은 파일은 사진별로 나눕니다. 결과는 고른 폴더에 바로 저장됩니다.

하는 일

  • 흰 여백 자동 자르기

    흰 바탕과 확실히 다른 부분만 남기고 둘레를 잘라 냅니다. 먼지 · 종이 얼룩 같은 작은 점은 무시합니다.

  • 자동 기울기 보정

    비스듬히 스캔된 사진의 테두리 각도를 재서 똑바로 돌립니다(±15°까지). 보정한 각도는 카드에 적힙니다.

  • 가장자리 흰 틈 제거

    살짝 기운 사진 모서리에 남는 흰 쐐기, 사진과 종이가 섞인 옅은 경계선까지 안쪽으로 다듬습니다.

  • 여러 장 자동 분리

    스캐너에 사진 여러 장을 한꺼번에 올려 찍은 파일은 사진마다 카드가 따로 생깁니다. 사진이 하나뿐이거나 문서면 그대로 둡니다.

  • 폴더에 바로 저장

    저장 폴더를 고르면 ZIP 없이 결과 파일이 그 폴더에 바로 생깁니다. '처리되면 바로 폴더에 저장'을 켜면 넣기만 하면 끝.

  • 한꺼번에, 빠르게

    여러 장을 한 번에 넣을 수 있고, CPU 코어 수만큼 나눠 동시에 처리합니다. 옵션을 바꾸면 모든 이미지에 바로 다시 계산됩니다.

  • 이 기기 안에서만

    모든 처리는 브라우저(또는 설치한 앱) 안에서 합니다. 이미지는 서버로 전송되지 않고, 한 번 연 뒤로는 인터넷 없이도 됩니다.

  • 회전 · 여백 · 저장 형식

    '고급 설정'에서 90° 회전, 결과 둘레 여백, JPEG 품질 · PNG를 고릅니다. 평소엔 접혀 있고, 고른 값은 기억합니다.

쓰는 법

  1. 저장 폴더 고르기 (선택) — '폴더 선택'으로 결과를 넣을 폴더를 정하고 '처리되면 바로 폴더에 저장'을 켭니다. 다음에 열어도 기억합니다.
  2. 이미지 넣기 — 끌어다 놓거나, 눌러서 고르거나, Ctrl+V로 붙여 넣습니다. 여러 장을 한 번에 넣어도 됩니다.
  3. 결과 확인 — 카드마다 왼쪽이 원본(잘릴 영역은 빨간 점선), 오른쪽이 결과입니다. 한 장만 돌리려면 카드의 ⟲ ⟳.
  4. 저장 — 폴더를 골랐으면 이미 저장돼 있습니다. 아니면 카드의 '다운로드'나 '전체 ZIP 다운로드'로 받습니다.

파일 이름은 원본이름_crop.jpg, 한 파일에서 여러 장으로 나뉘면 원본이름_crop_1.jpg · _2 …

받기

두 가지 모두 하는 일은 같습니다. 바로 써 보려면 웹에서, 폴더 저장을 늘 쓰거나 탐색기에서 바로 열고 싶으면 설치 파일을 받으세요.

  • 웹에서 바로 쓰기 휴대폰 · PC 브라우저에서 yh-yeop.github.io/AutoCroper. Edge · Chrome에서는 '앱으로 설치'로 독립 창 앱처럼 두고, 인터넷 없이도 씁니다. 폴더에 바로 저장도 Edge · Chrome에서 됩니다.
  • Windows 설치 파일 AutoCroper-Setup-버전.exe를 받아 실행합니다. 설치 폴더를 고를 수 있고, 바탕화면 · 시작 메뉴 바로가기가 생깁니다. 탐색기에서 이미지를 오른쪽 클릭 → '연결 프로그램 → AutoCroper'로 바로 엽니다.
웹에서 바로 쓰기 Windows 설치 파일 .exe
  • 코드 서명이 없는 설치 파일이라 처음 실행할 때 Windows가 'PC 보호' 창을 띄울 수 있습니다. 추가 정보 → 실행을 누르세요.
  • 설치 마법사에서 설치 폴더를 직접 고를 수 있습니다.
  • 자동 업데이트: 켤 때와 6시간마다 새 버전을 확인해 뒤에서 받아 두고, 준비되면 '다시 시작해 업데이트'가 뜹니다. 그냥 닫아도 다음 실행 때 설치됩니다.
  • 지우기: Windows 설정 → 앱 → AutoCroper → 제거.

알아 둘 것

어떤 이미지에 잘 맞나요?
흰 종이 · 흰 배경 위의 사진과 스캔본에 맞춰 만들었습니다. 바탕이 회색이나 색지면 여백을 잘 찾지 못할 수 있습니다. 연한 부분이 잘려 나가면 고급 설정의 '흰색 임계값'을 낮추세요.
여러 장이 나뉘지 않아요
사진과 사진 사이에 눈에 보이는 흰 틈이 있어야 나뉩니다. 서로 닿아 있거나 틈이 아주 좁으면 한 장으로 남고, 아주 작은 사진은 따로 잡히지 않습니다.
한 장이 둘로 잘못 나뉘었어요
날아간 하늘 · 흰 벽처럼 넓고 완전히 흰 띠가 사진을 가로지르면 두 장으로 나뉠 수 있습니다. 카드의 '분리 취소'를 누르면 원래 한 장으로 돌아갑니다. 아예 끄려면 고급 설정의 '여러 장 자동 분리'.
기울기가 보정되지 않아요
±15°까지, 테두리가 곧은 사진에만 적용합니다. 테두리가 들쭉날쭉한 문서 · 그림은 일부러 그대로 둡니다. 옆으로 누운 사진은 90° 회전 버튼으로.
'폴더 선택'이 안 보여요
폴더에 바로 저장하는 기능은 Edge · Chrome과 Windows 설치판에서 됩니다. 다른 브라우저(Firefox · Safari 등)에서는 '다운로드' · '전체 ZIP 다운로드'로 받으세요.
안 열리는 사진이 있어요
HEIC처럼 브라우저가 열지 못하는 형식은 지원하지 않습니다. 아이폰 Safari는 아주 큰 결과(약 1,670만 화소 넘게)를 만들지 못할 수 있고, 그때는 카드에 안내가 뜹니다.
