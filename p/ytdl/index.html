YTDL 유튜브 → MP3

유튜브 영상을 커버 · 싱크 가사가 들어간 MP3로

유튜브 링크를 넣으면 채널을 알아보고 아티스트 · 앨범 · 커버를 채운 MP3로 받습니다. 영상에 자막이 있으면 싱크 가사(.lrc)도 함께 만듭니다. PC에서는 링크를 붙여 넣고, 휴대폰에서는 유튜브 앱의 [공유]에서 YTDL을 고르면 됩니다.

Windows .exe Android .apk

무료 · 광고 없음 · Windows 10 · 11 · Android · 자동 업데이트 · 받은 곡 점검은 MP3 Checker

하는 일

  • 링크만 넣으면

    채널을 알아보고 아티스트 · 앨범 · 앨범 아티스트 · 커버를 정리 스타일의 규칙대로 채웁니다. 다른 규칙을 쓰려면 '적용 규칙'에서 이 영상만 바꿉니다.

  • 싱크 가사(LRC)

    영상 자막 언어를 고르면 노래에 맞춰 흐르는 .lrc 가사를 mp3 옆에 함께 저장합니다. 자막이 없는 영상은 mp3만.

  • 검색어 · 재생목록

    링크 대신 '아티스트 곡명'을 넣으면 음원 영상을 찾아 줍니다. 재생목록은 곡 목록에서 넣고 뺄 곡을 고르고, 곡마다 손본 뒤 한꺼번에 받습니다.

  • 정리 스타일

    채널 → 아티스트 규칙, 제목에서 지울 이름, 콜라보 표기를 묶은 것. 불러온 영상의 채널로 규칙을 바로 만들고, 저장하기 전에 결과를 미리 봅니다.

  • 커버 고르기

    규칙 커버 · 영상 썸네일 · 정사각 썸네일 중에서, 또는 이미지 링크 · 붙여넣기 · 파일로 직접 지정합니다.

  • 폴더 · 취소 · 다시 받기

    이 곡만 다른 폴더에 받을 수 있고 최근 폴더를 기억합니다. 받는 중 취소하면 받다 만 파일은 남지 않고, 재생목록은 실패한 곡만 다시 받습니다.

  • MP4도

    보조 탭에서 영상을 화질만 골라 mp4로 그대로 받습니다(태그 · 가사 없이).

  • 설치 하나로

    변환에 필요한 프로그램(ffmpeg 등)이 모두 들어 있어 따로 깔 것이 없습니다. 새 버전은 알아서 받아 둡니다.

쓰는 법

Windows

  1. 링크 붙여 넣기 — 유튜브 주소(또는 '아티스트 곡명')를 넣고 [정보 가져오기]. 재생목록 주소도 됩니다.
  2. 확인 — 제목 · 아티스트 · 앨범 · 커버를 보고, 필요하면 고칩니다. 가사를 받으려면 자막 언어를 고릅니다.
  3. 받기 — [다운로드]. 저장 폴더에 제목.mp3와 제목.lrc가 생기고, [폴더 열기]로 바로 엽니다.

Android

  1. 유튜브 앱에서 [공유] — 공유 목록에서 YTDL을 고르면 링크가 들어가고 정보까지 바로 가져옵니다.
  2. 받기 — 확인하고 [다운로드]. 진행은 알림에 보여서 다른 앱으로 넘어가도 됩니다.
  3. 듣기 — 음악/YTDL 폴더에 저장돼 음악 앱에서 바로 보입니다. 하위 폴더 이름은 바꿀 수 있습니다.

받기

  • Windows 설치 파일 YTDL-Setup-버전.exe를 받아 실행하고 설치 마법사를 따릅니다. Windows 10 · 11.
  • Android APK YTDL-Android-버전.apk를 휴대폰에서 받아 엽니다. 설치 뒤 유튜브 앱의 [공유] 목록에 YTDL이 생깁니다.
Windows .exe Android .apk
  • 코드 서명이 없는 설치 파일이라 처음 실행할 때 Windows가 'PC 보호' 창을 띄울 수 있습니다. 추가 정보 → 실행을 누르세요.
  • Android는 Play 스토어 밖에서 받은 앱이라, 처음 열 때 '알 수 없는 앱 설치'를 받은 브라우저(또는 파일 앱)에 허용해야 합니다. 설치가 끝나면 다시 꺼도 됩니다.
  • 자동 업데이트: Windows 판은 켤 때와 6시간마다 새 버전을 확인해 뒤에서 받아 두고, 준비되면 [다시 시작해 업데이트]가 뜹니다. 그냥 닫아도 다음에 켤 때 적용됩니다. Android 판은 배너에 새 버전과 용량을 띄우고, 모바일 데이터일 때는 자동으로 받지 않습니다.
  • 업데이트는 받은 설치 파일의 크기와 sha256을 릴리스 값과 대조한 뒤에 설치합니다. 잘리거나 다른 파일이면 설치하지 않고 다시 받기를 권합니다.

데이터는 기기 안에
설정 · 정리 스타일 · 받은 파일은 모두 이 기기에 저장됩니다(Windows는 %APPDATA%\YTDL). 계정이나 로그인은 없습니다.
익명 사용 통계
사용 중인 기기 수를 세려고 무작위 설치 ID · 버전 · OS 종류만 하루 한 번 보냅니다. 처음 화면에서 알리고, 버전 옆 '통계 보내기'로 끌 수 있습니다.
PC에서 가사가 안 받아져요
유튜브가 자막을 받을 때 로그인을 요구할 때가 있습니다. 브라우저 확장으로 내보낸 유튜브 cookies.txt를 [쿠키 파일 선택]으로 지정하세요. 쿠키는 로그인 정보라 남에게 주지 마세요.
갑자기 받기가 안 돼요
유튜브가 바뀌면 받는 부품(yt-dlp)이 막힐 수 있습니다. 오류 카드의 [yt-dlp 갱신]을 누르면 앱 안에서 바로 새것으로 바꿉니다.
받은 곡을 정리하려면
MP3 Checker로 YTDL 저장 폴더를 열면 가사 · 커버 · 태그 상태를 한눈에 보고, 같은 정리 스타일 기준으로 고칠 수 있습니다.
